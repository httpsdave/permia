# Permia

A personal photography portfolio showcasing original shots from my [Instagram (@httpdaev)](https://www.instagram.com/httpdaev/). The project features a custom immersive gallery with horizontal scrollwheel navigation, layout transitions, and fluid SVG marble hover effects.
